# Этапы разработки MoneyMap

Первая публикация — не отдельная демо-страница, а закрытое приложение с настоящим API, базой и Google-входом. До завершения настройки доступа реальные финансовые данные не вводятся.

1. **Техническая основа.** Next.js на Vercel, маршруты `/api`, схема PostgreSQL, серверный расчёт, тесты и подключённый GitHub. Критерий: проект собирается, миграция проходит, неавторизованные запросы отклоняются.
2. **Первый рабочий деплой.** Отдельные проекты Supabase и Vercel только для MoneyMap, миграция, переменные Vercel, Google OAuth и список двух разрешённых пользователей. Проекты «Pisz po polsku» не меняются. Критерий: оба пользователя могут войти по ссылке, видят один семейный план, посторонний пользователь не имеет доступа.
3. **Полный месячный сценарий.** Счета и остатки, регулярные доходы и платежи, месячные снимки, распределение и переводы, фиксация, история. Критерий: можно составить и сохранить план следующего месяца без переноса старых остатков вручную.
4. **Проверка перед повседневным использованием.** Сквозные сценарии на тестовых данных, одновременное редактирование, ошибки и адаптивность, журнал и экспорт. Критерий: результаты проверок зафиксированы; только после этого вводятся реальные суммы.

Резервное копирование пока не включено по решению владельца проекта. Оно не заменяет тестирование и контроль доступа.
